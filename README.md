# Intelligent Dictionary with Auto-Suggestion

A browser-based version of the DSA project. It uses a Trie to store words and return prefix matches, with alphabetical or search-frequency ranking.

## Run it

Open `index.html` in a modern browser. No package installation or build step is needed. The app saves its word list and search counts in the browser's local storage.

## Features

- Live prefix-based suggestions
- Insert and delete words
- Search exact words and track search frequency
- Rank matches alphabetically or by search frequency
- Filter and browse the dictionary
- Keep dictionary entries between browser visits

The first visit loads a small sample dictionary. The original C++ implementation is in `pro.cpp`.

## Files

- `index.html` — page structure and controls
- `styles.css` — layout and styles
- `script.js` — Trie operations, suggestions, ranking, and local storage
- `pro.cpp` — original C++ console implementation
